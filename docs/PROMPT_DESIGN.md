# 🎯 ラップ生成プロンプト設計書

## 概要

OpenAI APIを使用したラップ生成のプロンプト設計と実例

## 現在のプロンプト（実装版）

実際のプロンプトは `src/lib/openai.ts` の `RAP_SYSTEM_PROMPT` に定義されています。

### 主な特徴

1. **韻を踏む仕組み**: 母音パターンマッチング
2. **履歴対応**: 過去の会話を参照して一言コメント
3. **応援トーン**: 元気がないユーザーを励ます
4. **文字数制限**: 150文字以内
5. **4行構成**: 読みやすい形式

### 出力形式

```
【過去の会話がある場合】
振り返りコメント

4行構成のラップ
韻を踏んだ応援メッセージ
温かいトーンで励まし
自然な流れで韻を使用

【初回の場合】
4行構成のラップのみ
```

## 実例

### ユーザー入力
```
目玉焼き、失敗しちゃった。
```

### 生成されるラップ
```
朝のミスも、君のドラマの展開、
落ち込むより、一歩前へ見解、
トースト焦げても、まだ間に合う、
次は笑える朝食に分解
```
